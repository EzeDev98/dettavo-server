# dettavo-server

Spring Boot service for Dettavo, a local-first, transcript-based audio and video editor. It runs on http://127.0.0.1:2060 and is used by dettavo-client on http://127.0.0.1:2061.

Install, run, pairing and configuration instructions will be added as the app is built. Decisions that change the technical guide are in docs/decisions.md.
